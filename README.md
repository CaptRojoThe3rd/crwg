
# CaptRojo's World Gen

This mod offers completely new world generation for Minecraft 1.7.10. It is currently in beta
and incomplete.

There are two world types offered: 'Normal' and 'Islands'. 'Normal' provides continental terrain
generation, with continents several thousand blocks wide separated by larger oceans. 'Islands'
provides small (few hundred blocks max) islands that are separated by large oceans.

## Dependencies

I haven't written Cubic Chunks support yet, so the mod still uses my "extended height limit" forks
of ChunkAPI and EndlessIDs. (They aren't very good; I'd wait for Cubic Chunks support before you
consider using this mod in your modpack.)

* [Chunk API (E.H.L.)](https://github.com/CaptRojoThe3rd/ChunkAPI)
* [Endless IDs (E.H.L.)](https://github.com/CaptRojoThe3rd/EndlessIDs)
* [UniMixins](https://github.com/LegacyModdingMC/UniMixins)
